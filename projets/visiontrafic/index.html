Data · Vision par ordinateur

VisionTrafic

Des images de webcams publiques à un tableau de bord : un pipeline de détection d’objets et de traitement de données.

Ouvrir l’application ↗

Python · YOLO · Flask · SQLite

Une chaîne de traitement complète

J’ai développé un pipeline qui collecte des images de webcams publiques par cron, détecte les objets avec YOLO et stocke les résultats sous forme structurée.

Rendre les données consultables

Une API REST Flask alimente un tableau de bord. L’ensemble est déployé sur un VPS Linux, avec SQLite pour le stockage.
